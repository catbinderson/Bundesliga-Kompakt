# Bundesliga-Kompakt

Eine installierbare Bundesliga-Web-App mit Live-Ergebnissen, ausführlicher Tabelle, Spielplan und persönlicher Lieblingsverein-Ansicht. Die Daten stammen von OpenLigaDB.

## Funktionen

- Aktueller Spieltag mit Ergebnissen und Anstoßzeiten
- Tabelle mit Siegen, Unentschieden, Niederlagen und Tordifferenz
- Alle 34 Spieltage auswählbar
- Lieblingsverein mit nächsten Spielen und letzten Ergebnissen
- Offline-Anzeige und zwischengespeicherte Daten
- Für Smartphone und Desktop optimiert
